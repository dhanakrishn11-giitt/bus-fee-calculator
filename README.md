# Campus EV Fee Calculator
Students log EV trips (₹15 each). Office staff view monthly dues, mark payments, and download PDF receipts.

## Run
1. Install Node.js (LTS) from https://nodejs.org
2. `npm install`
3. `npm start`
4. Open http://localhost:3000

Admin login (default): `admin` / `admin123` (change with env vars ADMIN_USER, ADMIN_PASS).
